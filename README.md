# easy_Auth

A login service built as a college project in February and March 2017. It is kept as a record.

**Do not run it and do not copy from it.** It stores passwords in a form that can be reversed, and that is not its only fault. What I found on running it again in 2026 is written up at <https://thangaram611.github.io/projects/easy-auth/>.

The history was rewritten in November 2026 to remove a database login committed in 2017.
The repository itself was then deleted and created again under the same name, so that the old commits could no longer be fetched. That is why GitHub shows it as created in 2026; the commits keep their original dates.
